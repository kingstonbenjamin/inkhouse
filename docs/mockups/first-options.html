What you can customize (everything, since we write the page)

  • Which tiles appear, their order, names, size (1 or 2 columns) and grouping into tabs.
  • Tile type: on/off, temperature steps, scene, script, read-only value, or a confirm-first button.
  • Font size, border thickness, inverted "on" look, number of columns, how often it refreshes.
  • Your own rules: for example "unlock needs a second tap" or hiding the lock at night.
  • Any HA value on screen: kWh today, NAS temperature, humidity, hours the AC ran.

Limits

  • The Kindle's browser is old, so simple layout and plain JavaScript only. No animation.
  • Tapping redraws the page, and e-ink flashes on each full refresh.
  • It updates only while the page is open and awake.
  • Existing ready-made version: Kindle-Home-Assistant-Remote (derekmcauley7), or we build our own.

What you can customize

  • Which buttons appear, their labels and their order (edited in one text config file).
  • Each button can run any HA action: toggle, set temperature, run a script, lock, start the vacuum.
  • Status popups: any value or HA template ("AC today: 8.4 kWh").
  • Open it from the menu or bind it to a gesture, such as a long-press in a screen corner.
  • It sits on top of your books, so it works from inside the reader.

Limits

  • A plain text list only. No tiles, no sliders, no live state on the buttons.
  • Config is a hand-written Lua file, so one wrong comma breaks it. I can write it for you.
  • Changes need a KOReader restart to show. No HTTPS support, plain HTTP only.
  • One ready-made plugin (moritz-john/homeassistant.koplugin). A custom one means writing Lua.
